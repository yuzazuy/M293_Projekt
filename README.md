# M293_Projekt
## Eigene Webseite erstellen
Meine Webseite ist von ein Hotel, in dem Katzen leben. 
Man kann Zimmer für sich alleine, mit Freunden oder der ganzen Familie buchen und man ist immer in der Nähe von Katzen.
Viele Menschen können aus diversen Gründen keine eigenen Haustiere haben und in diesem Hotel, können sie neue Tierfreundschaften schliessen und die Wärme und Zuneigung von Katzen spühren.

## Tools
Es wurde alles mit HTML/CSS und ein wenig JavaScript in VSCode gemacht.
